Основной файл: report.tex. Выполнены задания 1–5 и численный эксперимент; задание 6 исключено.

## Сборка отчёта
Загрузить report.tex и папку figures в Overleaf, выбрать компилятор pdfLaTeX.
Либо в локальной установке TeX Live / MiKTeX с поддержкой русского языка выполнить:

    pdflatex -interaction=nonstopmode -halt-on-error report.tex
    pdflatex -interaction=nonstopmode -halt-on-error report.tex

Рисунки уже включены в комплект: запуск Python для сборки отчёта не требуется.
В среде подготовки не установлен движок TeX, поэтому PDF не скомпилирован и в комплект не входит.
Проверены парность окружений и скобок, ссылки на метки и наличие изображений;
это не заменяет пробную компиляцию и визуальную проверку вёрстки.

## Воспроизведение расчётов

    python -m pip install -r requirements.txt
    python experiment.py

Скрипт заново создаёт четыре рисунка и файлы:
- errors.csv: E2 = интеграл квадрата ошибки, E = его квадратный корень,
  relative_E = E / норму исходной функции;
- coefficients.csv: коэффициенты c_k, k=0,...,9;
- validation.json: версии библиотек и результаты проверок.

Во всех трёх системах использованы 10 функций и одна норма L2(0,1).
Бесселева система J0(j_k sqrt(t)) выбрана для общего веса 1, а не x.
При нормировке используется абсолютное значение J1(j_k).
Для e^t / Legendre ошибка дополнительно вычисляется с 60 десятичными знаками;
в остальных случаях интегрируется непосредственно квадрат невязки.
